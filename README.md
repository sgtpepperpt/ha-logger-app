# Logger for Home Assistant

A Home Assistant integration for a self-hosted Logger server.

## Install

1. HACS → ⋮ → **Custom repositories**.
2. Add `https://github.com/sgtpepperpt/ha-logger-app`, type **Integration**.
3. Open *Logger* in HACS → **Download**, then restart Home Assistant.

## Setup

Settings → Devices & services → **Add integration** → *Logger*, then enter the server's LAN
address, e.g. `http://<host>:4173`.
